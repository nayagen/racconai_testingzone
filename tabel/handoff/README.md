# Табель HR — пакет для разработки

Пакет передаёт фичу «Табель» из дизайна в разработку Платформы RaccoonAI (монорепа: бэкенд на Go, фронтенд на React + Tailwind, PostgreSQL, ClickHouse для GPS).

## Что внутри

| Путь | Что это |
|---|---|
| `SPEC.md` | Продуктовая спецификация: роли, пути водителя, грузчика и HR, бэкенд-процессы (в том числе сверка с опорным событием по pickup location id), абстрактные эндпоинты, настройки и пороги, открытые вопросы. Живая версия: https://claude.ai/artifact/7yevYjwQyvVT3HPEZTvW4y |
| `screens/*.dc.html` | Исходники 7 экранов из макета «Табель HR» (см. таблицу ниже) |
| `design-system/tokens.css`, `tokens.json` | Токены RaccoonAI Design System: цвета (surface/text/border/icons/status), отступы `--space-*`, радиусы `--radius-*`, типографика `--text-*` |
| `design-system/components/` | Бандл компонентов `RaccoonDS.*` (`bundle.js`, `bundle.css`) и их пропсы (`index.d.ts`) |

| Файл | Экран |

## Как читать `.dc.html`

Это макеты для редактора дизайна Claude, а не готовый продакшен-код. Отдельно в браузере они не откроются: рантайм редактора (`support.js`) в пакет не входит. Используйте их как точный референс:

- **Разметка внутри `<x-dc>`** — структура экрана. Инлайн-стили задают отступы, цвета и радиусы через токены (`var(--space-4)`, `var(--surface-primary)` …).
- **`<x-import component-from-global-scope="RaccoonDS.Button" …>`** — компонент дизайн-системы с пропсами. Сопоставьте его с компонентом в кодовой базе Платформы; пропсы описаны в `design-system/components/index.d.ts`.
- **`{{name}}`** — значение из `renderVals()` в блоке `<script data-dc-script>` внизу файла. **`<sc-for>`** — цикл, **`<sc-if>`** — условие.
- **Скрипт внизу файла** содержит моковые данные и логику прототипа: состояния, фильтры, пересчёт периода, тексты. Это подсказка, какие поля нужны API (сравните с разделом «Эндпоинты» в `SPEC.md`), а не реализация.
- **`<helmet><style>`** — ховеры и фокусы. Например, в `Main.dc.html` есть подсветка строки и столбца таблицы при наведении на ячейку, имя или дату.

## Порядок работы

1. Прочитать `SPEC.md` целиком, особенно «Бэкенд-процессы», «Эндпоинты» и «Открытые вопросы».
2. Подтвердить с продуктом (Аян) открытые вопросы, которые блокируют модель данных.
3. Бэкенд: отметки → геозона → сверка с опорным событием → расчёт → исключения → таймеры.
4. Фронтенд: экраны в порядке 1 → 3 → 2 → 4 → 5 → 6, на компонентах и токенах дизайн-системы, без захардкоженных цветов и отступов.

Версия дизайн-системы в пакете: `1793218213-9641` (RaccoonAI Design System for Claude).
